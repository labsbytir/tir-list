# Spec Delta

## Purpose
Contributors MUST submit entries without hand-editing JSON.

## ADDED Requirements

### Requirement: Submit form
`/submit` MUST collect category, slug, name, description, URL, tags, and optional links/install, then open GitHub's prefilled new-file page for review and PR.

#### Scenario: Submit an entry
- **WHEN** a visitor completes the form
- **THEN** a new tab opens with the file path and JSON prefilled, ready to propose
