# Spec Delta

## Purpose
The site MUST use the brand palette for page, cards, controls, and chart.

Palette: `--black #020202`, `--evergreen #0d2818`, `--black-forest #04471c`, `--sea-green #058c42`, `--malachite #16db65`.

## ADDED Requirements

### Requirement: Branded theme
Page background, cards, controls, links, and chart MUST use brand colors with readable contrast.

#### Scenario: Load with brand
- **WHEN** a visitor loads `/`
- **THEN** the page shows the dark forest theme with malachite accents and a matching chart
