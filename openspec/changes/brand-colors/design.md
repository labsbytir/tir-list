# Design

## Approach
- CSS vars from user palette on `:root`; `color-scheme: dark`; body gradient evergreen→black.
- Cards evergreen bg + sea-green border; links/buttons malachite accents.
- Chart: `Bar fill #16db65`, grid `#04471c`, ticks `#16db65`, dark tooltip.

## Alternatives
- Light-mode variant: rejected, palette is dark-first; revisit only if requested.
